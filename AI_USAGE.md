# AI Usage

I used AI tools during this assignment to get help with understanding
the task, writing some code, fixing errors and improving the project
step by step.

The main areas where I used AI assistance were:

- Understanding the web scraping task
- Creating and improving the scraper code
- Cleaning and standardizing the scraped data
- Creating validation checks
- Implementing duplicate record checking
- Debugging Python errors
- Connecting the different processing steps
- Preparing the project documentation

I tested the code on my local system and checked the output after each
step.

The final project was run successfully and produced:

- 1000 book records
- 100 quote records
- 1100 cleaned records
- 1100 valid records
- 1100 final records

The final output was saved in:

`output/deduplicated_data.json`

AI was used as a support tool, while I tested and verified the code
and results on my own system.
